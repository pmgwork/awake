This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 3

- Redesigned the menu bar cup icon with a top-down angle and fixed drawing size, filling with orange for manual Keep Awake, monochrome template tinting for automatic Keep Awake, and a top-right blue dot when cooling is active, while removing the idle indicator dot.
- Removed the **Show Remaining Time in Menu Bar** option from **Settings → General**, the welcome guide, and menu bar icon rendering.
- Added **While Rendering** as an automatic Keep Awake condition alongside **While Agent Is Running** and **While Downloading**, updated `RenderMonitor` and CLI status output accordingly, and synced documentation across the English, Japanese, and Chinese READMEs.
- Fixed **Settings** window sizing so the window resizes cleanly before tab switches, follows live content height changes while open without leaving extra space or stale scrollbars, and restores properly when closed and reopened.
- Prevented **Settings → Cooling** and **Settings → Keep Awake** from briefly flashing the helper authorization hint or disabling controls before the first helper check completes or while re-checking an already authorized helper.

This release also builds on [Beta 3](https://github.com/PMGWork/awake/releases/tag/v0.6.1-beta.3), [Beta 2](https://github.com/PMGWork/awake/releases/tag/v0.6.1-beta.2), and [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.1-beta.1).

## Installation

Download `Awake-0.6.1-beta.4.zip` or `Awake-0.6.1-beta.4.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
