This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 9

- Fixed the **Keep Awake After Agents Finish** duration menu so every option follows the selected app language. Previously the popup could show the selected value in Japanese while the other menu items stayed in English.
- Switching the app language now rebuilds the duration menu immediately instead of leaving stale labels behind.

This release also includes the fixes from [Beta 9](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.9) and earlier betas.

## Installation

Download `Awake-0.6.0-beta.10.zip` or `Awake-0.6.0-beta.10.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
