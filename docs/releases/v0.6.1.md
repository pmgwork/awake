## What's Changed

### Keep Awake and Menu Bar

- **While Agent Is Running**, **While Downloading**, and **While Rendering** now have independent switches, so you can enable any combination together or alongside manual Keep Awake. Ending one condition no longer stops Keep Awake while another condition remains active.
- Replaced the manual mode radio buttons with single-row presets: **∞**, **15m**, **30m**, **1h**, and **2h** for Keep Awake (**∞** = **Indefinitely**), and **∞**, **5m**, **10m**, **15m**, and **30m** for cooling. Previously saved durations are retained.
- Right-clicking the menu bar icon now starts or stops manual Keep Awake while leaving automatic conditions controlled by their switches.
- Redesigned the menu bar cup icon with a top-down angle and fixed drawing size: orange fill for manual Keep Awake, monochrome template tinting for automatic Keep Awake, and a top-right blue dot when cooling is active (idle dot removed).
- Removed **Show Remaining Time in Menu Bar** from **Settings → General**, the welcome guide, and menu bar icon rendering.
- Moved countdowns into existing rows and placed activity details (**Running Agents**, **Rendering Apps**, and **Downloads**) below the cooling controls so changing activity does not shift main controls.

### Cooling

- Automatic and manual cooling can now be enabled together. Choosing a manual duration leaves **While Keep Awake Is On** enabled; manual cooling uses the manual fan speed while it runs, and automatic cooling continues afterward when its conditions apply.
- Added automatic **While Rendering** cooling under **Cooling Mode**, using the automatic fan speed while rendering (with the lid open or closed) and stopping at the low-battery cutoff.
- Existing automatic settings and paused states are migrated; manual cooling is not restarted after relaunching the app.
- Allowed turning off an enabled automatic cooling switch from the menu bar popover during low-battery cutoff while continuing to block turning switches on.
- Stopped the AC-only `caffeinate` fallback process when switching to battery power while the lid is closed.

### Rendering and Agent Monitoring

- Added rendering detection in **Settings → Monitor** for **Blender** (CLI renders and in-app renders via startup script integration), **Adobe After Effects** (`aerender` and render queue monitoring via macOS Automation), **Adobe Media Encoder** (sustained CPU/GPU export load, including fixed child process discovery), and **Houdini** (`husk` / `mantra`).
- Refined **Settings → Monitor**: ordered sections as **Agents**, **Rendering**, and **Downloads**, ordered agents as **Codex**, **Claude Code**, **Antigravity**, and **OpenCode**, aligned row heights, replaced the manual Refresh button with automatic refreshes on view/app activation, and added section descriptions.
- Detected the **Antigravity** desktop app (`Antigravity.app`, `com.google.antigravity`) in **Settings → Monitor** and the welcome guide even when the `agy` CLI is not installed, transitioned Antigravity sessions to idle on `Stop` regardless of `fullyIdle`, and added `transcriptPath`-based recovery to clear orphaned sessions when `Stop` is missed while keeping long-running tool calls active.

### Command Line

- Updated CLI commands for independent automatic controls: `awake auto <agent|download|render> <on|off>`, `awake cooling auto <awake|render> <on|off>`, `awake mode` / `awake cooling mode` (`indefinitely` or `timer`), and `--all` support on `awake stop` / `awake cooling stop`.
- Extended `awake status --json` with `renderMonitoringEnabled`, `renderActive`, `cooling.renderEnabled`, `cooling.renderActive`, `cooling.automaticEnabled`, `cooling.automaticActive`, `cooling.manualArmed`, and `cooling.manualActive`.

### Settings and Documentation

- Fixed **Settings** window sizing across tab switches, live content height changes, and reopen.
- Prevented **Settings → Cooling** and **Settings → Keep Awake** from briefly flashing the helper authorization hint or disabling controls before or during helper state checks.
- Updated welcome guide descriptions, refreshed `Picker` popup items immediately on language changes in **Settings → General** (**Language**) and **Settings → Keep Awake** (**Stop at Battery Level**), and synced the English, Japanese, and Chinese READMEs.

## Installation

Download `Awake-0.6.1.zip` or `Awake-0.6.1.dmg` and move `Awake.app` to `/Applications`. Existing users can also use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
