This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 1

- Limited the low-battery cooling cutoff to **While Agent Is Running**. Manually started **Indefinitely** and **For Duration** cooling continue running.
- Added a notification and a menu explanation when low battery stops automatic cooling. Cooling can resume once the battery recovers or the Mac is plugged in.
- Preserved a manually started Keep Awake session's low-battery override when connecting or disconnecting the power adapter.
- Kept cooling available when a helper status check times out.
- Added periodic checks to reapply the selected fan speed if macOS takes back fan control, and retries when enabling manual fan control fails. Improved manual-mode detection on M3 and M4 Macs.

This release also includes the Low Power Mode and cooling settings introduced in [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.1).

## Installation

Download `Awake-0.6.0-beta.2.zip` or `Awake-0.6.0-beta.2.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
