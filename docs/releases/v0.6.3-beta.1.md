This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## Hardware Helper

- Fixed a helper installation failure that could prevent the administrator prompt from appearing when the installed compiler and macOS SDK were incompatible. Awake now includes a prebuilt, signed hardware helper. Installing or updating it in **Settings → Permissions** no longer requires Xcode or Command Line Tools. macOS still asks for administrator authorization when needed.
- If Awake already shows **Helper Authorized**, you can keep using your installed helper.

## Installation

Awake requires macOS 26.0 or later and supports Apple silicon and Intel Macs. Download `Awake-0.6.3-beta.1.zip` or `Awake-0.6.3-beta.1.dmg` and move `Awake.app` to `/Applications`. If you already receive beta updates, use **Settings → General → Check Now**.
