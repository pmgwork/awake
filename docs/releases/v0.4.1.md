## What's Changed

- Closed-lid operation and fan control now use a shared helper for administrator privileges. The helper can be installed, updated, reinstalled, or removed from Settings.
- Closed-lid operation and cooling can no longer be enabled when the helper is missing or outdated. After successful authorization, the corresponding setting in the current pane is enabled automatically.
- Removing permissions now stops Keep Awake and confirms that the closed-lid override has been released and the fans have returned to automatic control before removing the helper.
- Fixed display-sleep prevention in clamshell mode with an external display connected. The closed-lid sleep override is not applied in this state.
- Fixed OpenCode disconnect handling so Keep Awake stops and the connection is reestablished automatically. Also fixed delayed events reopening an old session after it had finished.
- Added an in-app display-language selector and revised Japanese wording and settings labels.
- Removed the legacy screen-lock grace-period feature. Recovery of settings changed by older versions is retained.

## Upgrade Notes

If you use closed-lid operation or fan control, update the helper using **Update** in Settings. Administrator authorization is required.

## Installation

Download `Awake-0.4.1.zip` or `Awake-0.4.1.dmg` and move `Awake.app` to `/Applications`. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
