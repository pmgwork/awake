This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 5

- Fixed repeated administrator password prompts when Awake couldn't return the fans to automatic control without the helper. Automatic retries no longer ask for a password; only explicit actions, such as ending a fan test or removing hardware authorization, may ask.
- Fixed a false "fans may still be under manual control" warning at launch on M3 and M4 Macs, where macOS can report a protected system fan mode that is not manual control.
- Linking or unlinking OpenCode now keeps the comments, trailing commas, and formatting in `opencode.jsonc` and `opencode.json`. Only Awake's plugin entry changes. Configurations with a comment after a trailing comma are now read correctly.
- **While Downloading** no longer stays on because of leftover partial files, such as `.part` files inside extracted archives. Partial files in subfolders of the download folder now count only while they are being written (changed in the last 10 minutes). Files directly in the folder are detected as before.
- Reduced background work: lid, display, and power changes, and sleep-prevention status, now update the menu and settings only when they actually change. Awake also checks an outdated helper less often and no longer logs a missing helper every second.

This release also includes the command-line tool, cooling fixes, and other changes from [Beta 5](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.5) and earlier betas.

## Installation

Download `Awake-0.6.0-beta.6.zip` or `Awake-0.6.0-beta.6.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
