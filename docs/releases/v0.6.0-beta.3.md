This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 2

- Fixed high background CPU usage when many completed agent sessions have accumulated. Awake now caches session snapshots and uses filesystem change notifications instead of repeatedly reading and parsing every session file.
- Replaced frequent recursive download-folder scans with filesystem change notifications, with periodic recovery scans for missed events.
- Stop disabled monitors to avoid unnecessary background work. Agent monitoring continues when needed for **While Agent Is Running** cooling.
- Prevented an in-progress scan from restoring stale activity after monitoring is stopped or the download folder is changed.

This release also includes the Low Power Mode and cooling improvements from [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.1) and [Beta 2](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.2).

## Installation

Download `Awake-0.6.0-beta.3.zip` or `Awake-0.6.0-beta.3.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
