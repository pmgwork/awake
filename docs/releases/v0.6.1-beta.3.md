This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 2

- Fixed child process discovery for **Adobe Media Encoder** load monitoring so `proc_listchildpids` counts are no longer divided by PID byte size, preventing child processes from being dropped when 1–3 child processes exist.
- Fixed menu bar remaining-time text contrast when automatic Keep Awake monitoring uses the orange non-template cup icon, resolving `labelColor` against the status button's current appearance and updating when the menu bar appearance changes.
- Fixed the **Adobe After Effects** toggle in **Settings → Monitor** so it stays off until linked, opens the link confirmation when toggled on, and clears the enabled state on **Unlink**.
- Stopped the AC-only `caffeinate` fallback process when switching to battery power while the lid is closed.
- Allowed turning off an enabled automatic cooling switch (such as **While Rendering**) from the menu bar popover during low-battery cutoff while continuing to block turning switches on.
- Incremented `RenderMonitor` generation when changing monitored render apps so in-flight background samples cannot overwrite newly updated settings.
- Updated the welcome guide's right-click and cooling descriptions, refreshed `Picker` popup items in **Settings → General** (**Language**) and **Settings → Keep Awake** (**Stop at Battery Level**) immediately when switching languages, and synced documentation across the English, Japanese, and Chinese READMEs.

This release also builds on [Beta 2](https://github.com/PMGWork/awake/releases/tag/v0.6.1-beta.2) and [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.1-beta.1).

## Installation

Download `Awake-0.6.1-beta.3.zip` or `Awake-0.6.1-beta.3.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
