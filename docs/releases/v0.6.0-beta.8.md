This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 7

- Restored **Keep Awake After Agents Finish** in **Settings → Keep Awake**. Keep your Mac awake for a little longer after the last monitored agent finishes: Off, 1, 2, 3, 5, 10, 15, or 30 minutes. The default is 3 minutes, and previously saved durations are preserved.
- The menu shows the remaining time after completion. New agent activity cancels the countdown; the next completion starts a fresh countdown.
- Pausing agent monitoring, changing the Keep Awake mode, or reaching the battery cutoff ends the grace period immediately.

This release also includes the fixes from [Beta 7](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.7) and earlier betas.

## Installation

Download `Awake-0.6.0-beta.8.zip` or `Awake-0.6.0-beta.8.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
