This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed

- Added an option to enable macOS Low Power Mode while the lid is closed during a session and restore the previous setting afterwards.
- Added separate fan speeds for **Automatic Cooling** and **Manual Cooling**. Existing fan-speed preferences are carried over to both settings.
- Simplified cooling modes to **While Agent Is Running**, **Indefinitely**, and **For Duration**. Existing mode selections are migrated.
- Automatic cooling now runs only with the lid closed. With the lid closed and an external display connected, Awake leaves fan control to macOS and does not override closed-lid sleep or enable Low Power Mode.
- Improved hardware permission status and settings layout.
- Added **Receive Beta Updates** in **Settings → General**, off by default, and separate signed update feeds for stable and beta releases. Turning beta updates off does not downgrade the installed app.
- Simplified Software Updates by removing the extra beta-update explanation.
- Added a packaging check to prevent coverage files from being included in distributed apps.

## Installation

Download `Awake-0.6.0-beta.1.zip` or `Awake-0.6.0-beta.1.dmg` and move `Awake.app` to `/Applications`. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
