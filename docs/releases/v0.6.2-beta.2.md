This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 1

- When the hardware helper needs an update, the menu now shows a shorter one-line notice with an **Update…** button. Clicking it updates the helper right away, so you no longer need to open **Settings → Permissions**. The helper can still be updated from **Settings → Permissions**.

This release also builds on [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.2-beta.1).

## Installation

Download `Awake-0.6.2-beta.2.zip` or `Awake-0.6.2-beta.2.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
