This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 4

- Fixed **Indefinitely** and **For Duration** manual cooling not running while the lid is closed and an external display is connected. Manual cooling now works in every display setup; automatic agent cooling still leaves fan control to macOS in this clamshell state.

This release also includes the command-line tool and other changes from [Beta 4](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.4).

## Installation

Download `Awake-0.6.0-beta.5.zip` or `Awake-0.6.0-beta.5.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
