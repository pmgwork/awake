This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since 0.6.0

- **While Agent Is Running** and **While Downloading** now have independent switches. Enable both at once, or combine them with manual Keep Awake. Ending one condition no longer stops Keep Awake while another condition is still active.
- Automatic and manual cooling can now be enabled together. Choosing a manual duration leaves **While Keep Awake Is On** enabled. Manual cooling uses the manual fan speed while it runs; automatic cooling continues afterward when its conditions apply. The cooling button now starts or stops manual cooling, and the switch controls automatic cooling.
- Replaced the manual mode radio buttons with a single row of presets. Keep Awake offers **∞**, **15m**, **30m**, **1h**, and **2h**; cooling offers **∞**, **5m**, **10m**, **15m**, and **30m**. **∞** means **Indefinitely**. Previously saved durations are retained.
- Moved countdowns into existing rows and placed activity details below the cooling controls, so changing activity does not move the main controls.
- Right-clicking the menu bar icon now starts or stops manual Keep Awake. Automatic conditions remain controlled by their switches.
- Existing automatic settings and paused states are migrated. Previously inactive conditions stay off, and manual cooling is not restarted after relaunching the app.
- Updated CLI commands and JSON status for the independent controls. `agent` and `download` enable their automatic conditions; `cooling mode awake` enables automatic cooling without replacing a manual session. `stop` disables both automatic Keep Awake conditions and stops manual Keep Awake; `cooling stop` stops both automatic and manual cooling.

## Installation

Download `Awake-0.6.1-beta.1.zip` or `Awake-0.6.1-beta.1.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
