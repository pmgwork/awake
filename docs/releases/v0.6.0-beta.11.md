This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 10

- Combined **Prevent Display Sleep** and **Prevent Screen Saver and Auto-Lock** into a single **Keep Screen On** setting in **Settings → Keep Awake** and the welcome guide. It keeps the screen on and also prevents the screen saver and automatic lock. Previously, display sleep prevention had no effect while screen saver prevention was on. If either earlier setting was on, **Keep Screen On** is on.
- When a hardware helper from an earlier version is installed, the menu now explains that it must be updated and links to **Permissions**. Previously, the cooling controls disappeared from the menu without explanation.
- `awake status --json` now reports `mode` with the same names the command accepts (`agent`, `download`, `indefinitely`, `timer`) instead of internal names such as `whileAgentRunning`.
- Updated the cooling description in the welcome guide to match the current behavior.

This release also includes the fixes from [Beta 10](https://github.com/PMGWork/awake/releases/tag/v0.6.0-beta.10) and earlier betas.

## Installation

Download `Awake-0.6.0-beta.11.zip` or `Awake-0.6.0-beta.11.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
