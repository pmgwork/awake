## What's Changed

- Added **Receive Beta Updates** in **Settings → General**, off by default. Enable it to receive beta releases through in-app updates.
- Moved in-app update checks to separate signed stable and beta feeds. Existing installations can update to this release through the previous update feed.
- The beta feed also includes stable releases. Turning off beta updates stops future beta updates without downgrading the installed app.
- Kept the Keep Awake and cooling behavior from 0.5.0.

## Installation

Download `Awake-0.5.1.zip` or `Awake-0.5.1.dmg` and move `Awake.app` to `/Applications`. Existing users can also use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
