This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 3

- Fixed the Mac going to sleep when you unplugged an external display with the lid closed during Keep Awake. With **Stay Awake with the Lid Closed** on, Awake now keeps the Mac awake with the lid closed whether or not an external display is connected.
- Fixed the Mac going to sleep when the lid was closed while only AirPlay, Sidecar, or virtual displays were connected.
- Fixed Antigravity sessions sometimes remaining active after a missed Stop hook when the tail of a transcript landed in the middle of a multi-byte UTF-8 character, and cleared expired sessions from the in-memory cache immediately upon cleanup.
- Fixed a potential crash when a menu bar countdown ended, including at the end of **Keep Awake After Agents Finish**.
- Fixed closed-lid sleep assertions still being held on AC power when **Stay Awake with the Lid Closed** in **Settings → Keep Awake** was turned off or the hardware helper was unavailable.
- Made the low-battery cutoff turn off both **While Keep Awake Is On** and **While Rendering** cooling consistently, and send the automatic cooling stopped notification only when automatic cooling was actually running.
- Retried **Use Low Power Mode with the Lid Closed** automatically after installing or updating the hardware helper, ensured stale closed-lid sleep markers are recovered before removing the helper or starting a new session on launch, and guarded startup fan recovery from overwriting a subsequent mode change.
- Fixed power source detection so external UPS or accessory batteries do not overwrite the Mac's internal battery level or AC power status.
- Fixed OpenCode configuration lookup when `XDG_CONFIG_HOME` is set to an empty string, and formatted legacy sub-minute **Keep Awake After Agents Finish** values cleanly instead of showing `0 min`.

Low Power Mode with the lid closed and automatic cooling still apply only when no external display is connected. The helper is unchanged from Beta 3, so no helper update is needed.

This release also builds on [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.2-beta.1), [Beta 2](https://github.com/PMGWork/awake/releases/tag/v0.6.2-beta.2), and [Beta 3](https://github.com/PMGWork/awake/releases/tag/v0.6.2-beta.3).

## Installation

Download `Awake-0.6.2-beta.5.zip` or `Awake-0.6.2-beta.5.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
