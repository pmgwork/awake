## 変更内容

- 冷却モードを刷新しました。新しい「エージェント実行中」モードは選ぶだけで有効になり、エージェントの作業中だけファンを回します。「蓋を閉じている時だけ」「外部ディスプレイ接続時は macOS に任せる」「電源接続時のみ」を選べます。
- 設定画面を「一般」「Keep Awake」「監視」「冷却」「権限」の5つのタブに整理しました。ヘルパーのインストール・削除は「権限」タブにまとめています。
- ウェルカムガイドを作り直し、エージェントの連携、閉蓋・ファン用の権限、基本設定を順に設定できるようにしました。
- メニューバーで残り時間を表示し始めたときに、ポップオーバーとアイコンが横にずれる問題を修正しました。
- ポップオーバーの構成を見直し、実行中のエージェントとダウンロードの状況を Keep Awake の直下に表示するようにしました。
- エージェントを連携すると、そのエージェントの監視を自動でオンにするようにしました。
- 英語・日本語の表記を全体的に見直しました。
- 新規インストール時の初期設定を「エージェント実行中」モードにしました。既存の設定はそのまま引き継がれます。
- 設定画面のファンテストと、エージェント完了後の猶予時間の設定を削除しました。

## インストール

`Awake-0.5.0.zip` または `Awake-0.5.0.dmg` をダウンロードし、`Awake.app` を `/Applications` に移動してください。未公証のため、macOSに起動をブロックされた場合は「システム設定 → プライバシーとセキュリティ → このまま開く」を使用してください。

[変更一覧](https://github.com/PMGWork/awake/compare/v0.4.1...v0.5.0)
