## What's Changed

- Redesigned cooling modes. Selecting the new **While Agent Is Running** mode enables it immediately and runs the fans only while an agent is working. Options let you limit cooling to when the lid is closed, leave fan control to macOS when an external display is connected, or cool only on AC power.
- Organized Settings into five tabs: **General**, **Keep Awake**, **Monitor**, **Cooling**, and **Permissions**. Helper installation and removal are now in Permissions.
- Rebuilt the welcome guide to walk through agent linking, permissions for closed-lid operation and fan control, and basic settings.
- Fixed the popover and icon shifting sideways when the menu bar starts displaying the remaining time.
- Revised the popover layout to show active agents and download status directly below Keep Awake.
- Linking an agent now automatically enables monitoring for that agent.
- Fixed agent hooks creating `default.profraw` in the working directory. Awake now updates the hook bridge automatically at launch. Any existing `default.profraw` files created by these hooks can be safely deleted.
- Revised English and Japanese wording throughout the app.
- New installations now default to **While Agent Is Running** mode. Existing settings are preserved.
- Removed the fan test and the grace-period setting for cooling after an agent finishes from Settings.

## Installation

Download `Awake-0.5.0.zip` or `Awake-0.5.0.dmg` and move `Awake.app` to `/Applications`. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
