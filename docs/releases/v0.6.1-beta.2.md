This is a beta release. To receive it in-app, enable **Settings → General → Receive Beta Updates**.

## What's Changed Since Beta 1

- Added automatic **While Rendering** cooling under **Cooling Mode**. It uses the automatic fan speed while rendering, continues with the lid closed, and stops at the low-battery cutoff.
- Added rendering detection for **Blender** (both CLI renders and in-app renders through the **Settings → Monitor** integration), **Adobe After Effects** (`aerender` and render queue monitoring via macOS Automation), **Adobe Media Encoder** (sustained CPU/GPU export load), and **Houdini** (`husk` / `mantra`).
- Added **Rendering Apps** in the menu bar popover while **While Rendering** is active, and aligned **Running Agents** so it appears only when an agent is running.
- Refined **Settings → Monitor**: ordered sections as **Agents**, **Rendering**, and **Downloads**, ordered agents as **Codex**, **Claude Code**, **Antigravity**, and **OpenCode**, aligned row heights, replaced the manual Refresh button with automatic refreshes on view/app activation, and added section descriptions for **Agents** and **Rendering**.
- Updated CLI commands for independent automatic controls: `awake auto <agent|download> <on|off>` and `awake cooling auto <awake|render> <on|off>` toggle automatic conditions independently, `awake mode` and `awake cooling mode` accept `indefinitely` or `timer`, `awake stop` / `awake cooling stop` leave automatic conditions on unless `--all` is passed, and `status --json` adds `renderEnabled` / `renderActive` under `cooling`.
- Updated the **While Keeping Awake** header in **Settings → Keep Awake**, updated the **Settings → Cooling** mode footer, and refined Japanese UI wording.

This release also includes the independent Keep Awake and cooling controls introduced in [Beta 1](https://github.com/PMGWork/awake/releases/tag/v0.6.1-beta.1).

## Installation

Download `Awake-0.6.1-beta.2.zip` or `Awake-0.6.1-beta.2.dmg` and move `Awake.app` to `/Applications`. Existing users with beta updates enabled can use **Settings → General → Check Now**. The build is not notarized; on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS blocks it.
